# 茶叶拼配审评台

审评员对一个拼配批次打香气、滋味、汤色。服务端按 0.3 / 0.5 / 0.2 加权，7 分及以上通过。提交后只替换表格里新的一行，不整页跳转。

这是制茶审评，不是菜谱，也不是饮食记录。

## 杯温门禁

- 交评强制填写杯面温度，且必须落在审评员设定的温区**闭区间**内（初始 75℃–85℃）；区间外或缺填一律拒交，返回当前温区提示。
- 温区可在顶栏「杯温门禁」专页修改，改完只约束之后的提交，不溯及既往。
- 温度原文（逐字字符串）写入只追加履历；事后改正温度只 UPDATE 当前值并新增一行「改正」履历，早先那行数字永不覆盖。
- 只读账号可翻温区与履历，不可改温区、不可交评、不可改正温度。

## 验收

1. taster 登录后看到春茶-A 通过、夏茶-C 不通过。
2. 再提交一组高分，新行出现在表头，页面不整页刷新。
3. observer 登录后没有提交表单。
4. 温区 75–85 下：填 80 交评成功；填 60 被拒并提示当前温区；75、85 边界值可交（闭区间）。
5. 把该行温度改正为 82.5 后，门禁履历仍能看到早先的 80，且原文（如 `80.00`）逐字保留。
6. observer 可从顶栏进入「杯温门禁」查看温区与履历，但改温区、交评、改正温度均返回 403。
