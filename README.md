# 茶叶拼配审评台

审评员对一个拼配批次打香气、滋味、汤色。服务端按 0.3 / 0.5 / 0.2 加权，7 分及以上通过。提交后只替换表格里新的一行，不整页跳转。

交评还**强制填写杯面温度**，且必须落在审评员设定的**温区闭区间**内（默认 75–85℃）：

- 顶栏「杯温门禁」进入专页，可查看/修改当前温区与杯温履历；只读账号可翻页但不能改。
- 温区随时可改，**只约束之后的提交**，不追溯既有记录。
- 区间外（含改正温度）一律拒绝，并在提示中给出当前温区。
- 每次交评、事后改正的温度原文都写入 `cup_temp_events` 履历，**只追加**；改正只更新当前行温度，履历里早先那行数字永不覆盖。

这是制茶审评，不是菜谱，也不是饮食记录。

## 验收

1. taster 登录后看到春茶-A 通过、夏茶-C 不通过。
2. 再提交一组高分，新行出现在表头，页面不整页刷新。
3. observer 登录后没有提交表单。
4. 温区 75–85℃ 下：杯面温度填 80 交评成功；填 60 被拒并提示当前温区。
5. 把该行温度改正（如 82）后，杯温门禁履历中仍能看到早先录入的 80℃。
6. observer 可进「杯温门禁」翻温区与履历，但直接 POST 改温区 / 交评 / 改正均为 403。
